## 本次修复及回归约束

- Linux 安装目标改到 `bin/`，使 `$ORIGIN` 相对 RUNPATH 能找到随包 Qt 库。
- Qt provision/configure 增加 XCB 与 FFmpeg Multimedia 插件及动态依赖检查。
- 选择覆盖层资源初始化移到全局命名空间，消除 Linux 链接器解析到命名空间内资源符号的问题。
- XCB 覆盖层使用 `X11BypassWindowManagerHint`，防止 Xfce 将窗口从屏幕原点偏移到工作区原点；回归测试用 `xwininfo` 检查原生窗口坐标，避免只读取 Qt 请求值。
- GUI 测试等待系统托盘可用，避免 Xfce 面板启动期间的竞态。
- 独立审查后，Linux 验证会精确重建安装目录，逐文件哈希比较项目、Qt、SPDX、vcpkg 与 libcimbar 许可证语料，并拒绝安装包从开发 Qt 前缀解析库或插件。
- GUI CTest 同时具有 60 秒 CTest 属性与 75 秒外层超时；生产捕获源测试还会等待停止后的 inactive 通知。
