# Cimbarpunk 1.0.1 Release Implementation Plan

**Goal:** Upgrade libcimbar to the latest upstream release and publish Cimbarpunk 1.0.1 with verified binaries, recursive corresponding source, and SHA-256 checksums.

**Architecture:** Keep the existing decoder integration; upstream v0.6.8 changes only web/index.html and web/main.js relative to the previous pin. Synchronize the application version and dependency provenance, then run the existing complete Windows verifier and package its output.

**Tech Stack:** C++20, Qt 6.8.4, CMake, Ninja, CTest, PowerShell, GitHub CLI.

**Spec:** User release request, AGENTS.md, README.md, existing desktop decoder design.

## Constraints

- Work directly on main. The current explicit release request authorizes the minimal release commit, push, tag, and publication.
- Preserve Qt, FFmpeg and vcpkg pins. Pin libcimbar v0.6.8 to bfb0c8e471820ae493cd3694ea6bed5d5ac06c37; preserve its nested samples pin.
- Do not reuse old binaries as version 1.0.1. Linux publication requires fresh verification on an accessible host; the previous host timed out. macOS remains unverified.
- Include full corresponding recursive source and license materials.
